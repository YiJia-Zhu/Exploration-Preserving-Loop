# EP：基于 LoopOPD 保留有用的中间探索

状态：研究假设与候选方案；已完成[首轮工程、内部干预与短训](07_pilot_results_20261108.md)，尚未验证完整 EP。工作名 **Exploration-Preserving Loop（EP）**；不预先声明新颖性或有效性。

**方法来源：本 idea 直接来自对 LoopOPD 的改进。EP 沿用 LoopOPD 的跨轮 on-policy 蒸馏，在原有最终分布目标上加入经过任务价值验证的中间候选与修正监督。**第一版采用 LoopOPD 的冻结教师设置；D-LoopOPD 是后续扩展基础。

## 1. 研究故事

LoopOPD 用同一初始循环模型的深轮策略指导浅轮策略：两轮学生生成回答，冻结四轮教师在这些前缀上提供最终 token 分布。这使额外循环计算成为监督来源，也是 EP 继承的主框架。

循环模型在生成一个 token 之前，可以反复更新内部状态。后几轮可能纠正较早轮的判断，也可能重新组织检索、保持多个候选或完成暂时无法直接读出的计算。LoopOPD 直接对齐浅轮出口与深轮终点，对中间候选怎样演化没有显式目标。在有限计算、表示和训练预算下，学生可能学会终点倾向，却没有充分学会有助于新问题求解的比较和纠正。

**EP 要验证：LoopOPD 是否留下这类有用过程未被学会，以及在 LoopOPD 上增加选择性的过程监督能否改善它。**若训练后比原始浅轮学生进一步损失了有用候选，才支持更强的“蒸馏压缩了探索”表述；若只是没有恢复深轮能力，应称“有用过程迁移不足”。

主要动机论文是 [Cross-Loop Query Handoff](../ref/2610.34639v1_query_handoff.pdf)：Ouro 中查询的跨轮更新会影响两跳检索，冻结更新会消除增益，后轮查询移植可挽回部分早轮错误。它为中间计算的任务价值提供证据；LoopOPD 的受损现象与多候选探索价值仍需我们验证。详细数据、补充论文和论证边界见[动机与证据](06_loopopd_motivation_evidence.md)。

动态轮次对应、蒸馏位置选择和过程损失都是候选手段。它们本身已有相关方法，不能替代上述问题的证据。

## 2. 三种“探索”不能混为一谈

| 对象 | 可观测量 | 所需证据 |
|---|---|---|
| 中间预测中的候选保留与比较 | 候选概率、排名、支持集、非单调修正 | 采用／删除相应预测修正后，学生完成任务的变化 |
| 隐藏状态中的准备性计算 | 状态、attention/query、后继状态可用性 | 控制真实状态与缓存后的因果干预 |
| 最终输出采样的探索 | 解法覆盖、Pass@K、重复、熵 | 相同解码和总计算预算下的成功覆盖 |

多数循环更新不会在每一轮真正采样一个 token。固定前缀与初态后，轮间分布变化不能直接等同于随机动作探索。Huginn 的随机初态需要另行配对控制。

本文所说的“中间循环 token”具体指：同一输出位置在不同循环上的隐藏状态及其 token 分布读出。需要保留的是有助于后续任务的候选或计算功能；不要求把每一轮 top-1 token 当作额外文字输出或逐个模仿。

“有用”应由任务后果定义；高熵、大 KL、候选多只用于筛选。“必要”只在指定任务分布、学生与干预协议下使用，不能从有限实验推出普遍不可删除。

## 3. 从 LoopOPD 原目标出发

令 `c_t` 为学生生成的文字前缀；`p_T^r` 为教师第 r 轮的预测；`p_S^j` 为学生第 j 轮的预测。原生循环模型的一轮可能包含多层 Transformer。

第一版与 LoopOPD 原文 §4.1、Eq. (9) 对应：教师 `T` 是学生初始化模型的独立冻结副本，学生 `S` 更新共享循环参数。四轮教师教两轮学生，按回答长度归一化：

`L_LoopOPD = E_{x~D, y~π_S^2(·|x)}[ (1/|y|) Σ_t KL(p_S^2(·|c_t) || p_T^4(·|c_t)) ]`。

其中 `D` 是训练问题分布。下文 `L_end` 就是这个 LoopOPD 目标。学生前缀随当前两轮策略生成，即 on-policy；固定旧轨迹反复训练会偏离该设置。D-LoopOPD 则把教师目标换成当前共享模型的四轮分布，并停止目标侧梯度，不能把两种教师策略混报。

该目标没有唯一指定学生的内部计算路径；梯度仍经过学生的循环计算，并非中间状态完全没有训练信号。它不要求每一轮都变成相同分布。若学生在所有可达前缀上完全匹配教师最终条件分布，两者的输出序列分布也相同。因此，EP 研究现实中的学习与计算限制，不能声称终点匹配在理论上必然损失能力。

LoopOPD 是基础方法；OPTD 与 LoopGR 为新增过程项提供直接近邻与对照。EP 需要说明：原 LoopOPD 在哪些位置未保留有任务价值的过程，以及选择性辅助为什么比统一过程监督更有效。原 LoopOPD 是后训练方法，也报告深轮改善；EP 第一版把浅轮部署性能作为主要评价。

## 4. 第一版候选方法

保持 LoopOPD 的两轮学生、四轮冻结教师和学生生成前缀，只新增选择性的中间辅助。

```text
教师多轮轨迹 → 识别有用候选／修正 → 中间监督
教师最终预测 ─────────────────→ LoopOPD 原目标
                                  ↓
                           固定两轮学生
```

### 4.1 候选保留监督

从训练集合内的学生前缀中，找出经过干预验证、保留多个候选有助于完成任务的位置。第一版先选择一个固定的教师中间轮 k，比较 k=2 与 k=3；不是默认第 3 轮最好。

将教师中间分布 `q_E=p_T^k` 和学生第一轮分布，都聚合到同一事件空间：已选候选集合 `C_t` 加一个 `OTHER` 事件。单个候选保留原始概率，集合外概率加总到 OTHER。

`L_preserve = Σ_t g_t KL(q̄_E,t || p̄_S,t^1)`。

`g_t` 是停止梯度的非负门控／权重。只有开发协议认定有价值的位置才加辅助。这个目标既保留选定候选的相对关系，也保留它们的总质量；OTHER 内部不被逐 token 对齐。

候选初筛可以使用各轮 top-K 并集，但“值得保留”仍需收益证据。若只剩一个纠正候选，结果更接近纠错监督；尚不足以支持“多候选探索”解释。

### 4.2 关键修正监督

在相同候选空间，考察学生 S1→S2 的 log-probability 增量与教师中间态→T4 的增量。可先采用有界、加权的中心化增量误差：

`L_revision = Σ_{t,v} g_t w_{t,v} [center(Δ_S) − center(Δ_T)]²`。

其中 `Δ_S=log p_S^2−log p_S^1`，`Δ_T=log p_T^4−log q_E`。center 减去同候选空间上的加权均值。有限概率、候选空间、权重、裁剪与归一化要固定，不能把近似目标称为精确全词表 KL。

这个过程项与 OPTD／LoopGR 高度相关，是需要验证的适配，不是单独的新贡献。首先单独测试候选保留，再测试加入修正项是否真的有额外收益。

### 4.3 最终结果监督

继续保留真实教师终轮的 `L_end`，形成：

`L_EP = L_LoopOPD + λ L_preserve + μ L_revision`。

在相同数据、初始化、采样与更新设置下，`λ=μ=0` 退回 LoopOPD。再做 λ=0 或 μ=0 的逐项对照。辅助位置的密度、梯度尺度与额外计算，均与随机／均匀过程监督匹配。主评测使用普通固定两轮学生，不带教师干预。

## 5. 怎样识别“有用”

### 5.1 输出建议的价值

在同一学生状态和前缀上，替换一个候选 token，随后统一由固定两轮学生继续：

`Q_S(c_t,a) = E[采用 a 后由学生完成的最终奖励]`。

多个候选在配对续写中提供可靠成功机会，才为“保留探索空间”提供证据。仅观察教师偏好或一次成功不够。样本、阈值和预算均预先记录。

### 5.2 修正子集的价值

定义 `δ_r=log p_T^r−log p_T^{r−1}`。四轮教师有 r=2、3、4 三个修正。对其子集 G 构造：

`q_G = softmax(log p_T^1 + Σ_{r∈G} δ_r)`。

全部修正严格还原 T4。8 个子集可在小型先导诊断中枚举，用统一学生续写评价，检查哪些组合足以保持收益。这能检验修正间交互，不能把独立低收益修正直接判成冗余。

这是输出空间的干预，可能产生自然轨迹中没有的组合；它不等于撤销真实隐藏状态计算。Huginn 较多轮数不采用指数级穷举，先选少量区间。

### 5.3 监督的训练价值

采用教师建议有用，不保证把它教给学生就有用。先比较固定点位短训；若后续需要任务收益加权，比较 RAD、AOPD 与固定映射的合理适配，计入临时更新或分支成本。

## 6. 动态点位放在哪里

首轮先比较 `T2→S1、T4→S2` 和 `T3→S1、T4→S2`。若不同问题或训练阶段的最佳中间目标稳定不同，再让 `k_t` 按样本／位置变化。

选择标准应兼顾任务价值与学生能否接住，不能只按最小 KL 或最大熵。自动匹配已有 BERT-EMD、ALP-KD 等方法；动态选择必须超出最佳固定映射与随机匹配才值得保留。

## 7. 探索解释成立所需的证据

至少需要连接三件事：低预算压缩后有价值的候选／状态过程受损；相应干预能恢复后续表现；学生学习该过程后在新题上获益。

若普通熵正则或 Entropy-Aware OPD 已解释全部收益，应归因于输出分布正则。如果只有预测增量监督有效，主张应收窄为修正学习。如果只有隐藏状态准备性计算有价值、预测读出没有可用信号，当前输出空间 EP 方案可能不足，需要另研究机制监督。

当前不能声明：EP 已有效、深轮探索已被证明丢失、T3 普遍适合 S1、所有冗余可被识别，或方法已确认新颖。
