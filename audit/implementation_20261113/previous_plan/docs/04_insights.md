# EP Insights：证据、假设和决策

已完成[首轮局部干预及训练实现检查](07_pilot_results_20261108.md)，尚未验证完整 EP。下表中的“证据”仍指已有论文陈述；本地结果单列，不替代论文或完整假设的验证。

**研究起点固定为 LoopOPD 的改进。**我们继承其跨轮 on-policy 蒸馏，检验增加有用中间监督是否有效。主要动机证据是 Query Handoff；完整论证见[LoopOPD 动机与证据](06_loopopd_motivation_evidence.md)。

## 1. 可以直接采用的认识

| 认识 | 来源／证据范围 | 对 EP 的影响 |
|---|---|---|
| 终点损失不唯一确定内部轨迹 | 条件分布目标的性质 | 可以研究学习过程，但不能据此证明输出能力受损 |
| 若所有可达前缀的最终分布完全一致，序列分布也一致 | 自回归分解 | 问题应落在有限预算、表示与优化限制 |
| 部分跨轮查询更新对组合检索有任务作用 | Query Handoff 的 Ouro 合成任务冻结、移植及 donor 对照 | 可检验 LoopOPD 是否迁移该功能；尚不能称多候选探索已被证明 |
| 一轮不必是一项固定语义操作 | Shared Weights 的受控图任务与 Ouro 扩展 | 点位按功能研究，不能只按编号比例解释 |
| 答案可读出不保证状态可被后续重用 | Compute/Retain/Reuse 的受控任务 | 熵、答案概率或稳定性可能遗漏准备性计算 |
| 同一状态更像教师不保证学生学得更好 | AOPD、RAD、TA-OPD 分别提供不同诊断 | 输出价值、训练价值和局部可学性要区分 |
| 过程蒸馏、自动映射已有直接方法 | OPTD、LoopGR、BERT-EMD、ALP-KD | 不能以加过程 loss 或动态点位单独宣布创新 |
| 散度会影响学生输出熵 | Entropy-Aware OPD、Divergence/Entropy | 熵变化必须有散度基线 |
| 额外循环的读取、写入窗口随模型变化 | Jacobian Lens、Huginn 架构 | Ouro 与 Huginn 独立验证，不能共用轮次语义 |

## 2. 仍待验证的核心假设

| 编号 | 假设 | 支持它至少需要什么 |
|---|---|---|
| H1 | LoopOPD 的浅轮学生未充分迁移深轮有用候选或准备性过程 | 原始深／浅轮与 LoopOPD 浅轮的固定前缀变化 + 配对干预 + 任务后果 |
| H1b | 更强假设：LoopOPD 训练进一步压缩了原有的有用探索 | 相对原始同预算浅轮学生，有价值候选／过程减少；排除只是更确信正确答案 |
| H2 | 有用修正与大 KL／高熵不等价 | 与相同变化强度、长度和候选数的随机／启发式对照 |
| H3 | 学习这些过程能改善固定低预算学生 | 新题上的真实训练结果，超过一般过程监督 |
| H4 | 候选保留与最终结果监督具有互补性 | 两者单独与组合的消融，不只看内部指标 |
| H5 | 点位需随样本／学习阶段变化 | 动态选择超过最佳固定点位、随机和软 attention 映射 |
| H6 | 收益值得额外教师与分支计算 | 等总 FLOPs／时间，以及部署延迟比较 |

H5 不是启动 EP 的前提，属于后续扩展。如果 H1 尚不成立，不应直接把 H5 当主故事。

H1 可以成立而 H1b 不成立：LoopOPD 可能已有改善，只是尚未充分迁移教师过程。此时 EP 应写成对原方法的补充，不称原方法破坏探索。

## 3. 常见误读

- **轮间改变很大，所以一定有用。**可能只是格式或词形变化。
- **学生熵低，所以探索被破坏。**也可能更确信正确答案，或散度本来就改变熵。
- **某候选一次续写成功，所以应保留。**需要多次采样、对照和不确定性。
- **单次替换无收益，所以该修正冗余。**多个修正可能必须联合作用。
- **跳过循环会降分，所以这个预测增量必要。**少算本身与具体语义变化不同。
- **第一轮读出答案了，所以可以立刻停止。**后续可重用状态可能尚未准备好。
- **Query Handoff 已证明 LoopOPD 丢失探索。**该论文未测试 LoopOPD，也未证明多个候选的保留价值。
- **每一轮读出一个 token，所以每个中间 token 都应模仿。**循环主要更新隐状态，候选读出是观测接口；应验证具体功能的任务作用。
- **固定 T3 优于 T2，所以动态选择必然有价值。**固定最佳点位可能已经足够。
- **提高候选覆盖就等于提高能力。**候选、输出和最终成功率需要连接起来。

## 4. 按实验结果调整研究主张

| 结果 | 应如何解释与行动 |
|---|---|
| 读出或 cache 恒等检查不通过 | 修实现；不讨论探索机制 |
| 只观察到统计变化，没有干预价值 | 维持描述性观察，不称必要探索 |
| 熵基线已达到全部收益 | 主张收窄为输出多样性／散度选择 |
| 均匀过程监督与 EP 相当 | 收窄为已有过程蒸馏的适配价值 |
| 随机门控也相当 | 有用性选择未建立 |
| 只有一个关键候选纠正有效 | 可以研究纠错；多候选探索解释不足 |
| 隐藏状态有贡献，但预测读出不可用 | 当前输出空间方案不足，另研究状态功能监督 |
| 固定点位与动态点位相当 | 使用固定方案，不增加选择器 |
| EP 只在更多训练计算下获益 | 先比较同成本普通训练，不强调效率 |
| 两轮提高、四轮严重受损 | 报告共享权重代价，不能称多预算都更好 |

## 5. 当前最小贡献标准

需要同时给出：LoopOPD 中明确的过程迁移不足或探索受损类型；与真实任务后果相连的过程诊断；学生学习这些过程的效果；相对原 LoopOPD、普通过程、熵和随机对照的等预算收益。

若仅有“加一个 loss 后分数更高”，仍有明显增量风险。改名不能代替问题、机制和证据的区别。当前包保留这些反证条件，便于后续据结果收窄或修改方案。
