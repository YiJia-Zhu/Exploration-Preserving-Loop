# 当前 Idea：原生动态退出与 JS 阶段蒸馏

更新：2026-11-13。以[完整研究计划](loop_distillation_research_proposal_zh.md)为准。直接方法来源是 LoopOPD / D-LoopOPD；原先的候选保留辅助和 log-probability 修正项已退出当前主损失。

## 1. 要解决什么

在固定的浅轮推理预算下，怎样转移深轮教师中对正确性有贡献、又适合浅轮学生学习的更新？现有终点蒸馏提供最终预测，但没有显式指定学生中间轮承接哪些计算阶段。阶段监督能否改善学习，需要 A/B/C/D 实验验证。

本文的跨轮隐式探索指同一文字位置生成前的状态和预测更新，不等同于每轮采样一个 token。高 JS 只表示预测发生转折，不能自动认定该变化正确、有用或不可删除。

## 2. 三个深度

| 数量 | 定义 | Ouro 主设置 |
|---|---|---:|
| K | 教师统一最大循环上限 | 4 |
| n_t | 当前学生前缀上，教师原生退出规则选出的监督终点 | 每个 token 可不同，1–4 |
| S | 学生固定计算轮数 | 2 |

学生始终独立执行 S 轮生成回答。教师读取同一 `c_t=(x,y^S_<t)`，用自身计算与 KV；不把教师独立作答时的退出标签或学生 KV 用作当前监督。

## 3. 先定终点，再分阶段

Ouro 使用官方 gate 的 stick-breaking 退出分布及累计概率阈值，最后一轮接收剩余退出质量。阈值默认先用 0.9 作为开发起点，须在训练开发数据校准。原始 A 基线直接指定终点 K，不依赖 gate。

在 `q_1,…,q_n_t` 上计算标准 JS，使用自然对数，单位为 nats。将 `JS(q_(d-1),q_d)>τ` 的连接作为候选；最多保留 S−1 个最大的边界。并列值优先较早边界，选出的边界按轮次排序，每段取最后一轮。`τ=0.01` 只是初始开发值，不是 LoopOPD 报告的参数。

六轮示例若最大转折在 3→4，分段为 `[1,2,3]`、`[4,5,6]`，取教师第 3、6 轮。代码只在前 n_t 轮内选边界，不读取退出之后的变化作为选点依据。

没有超阈值转折，或 `n_t<=S` 时，只用 `q_n_t` 监督学生末轮。一般情形有 M 个阶段时，第 j 个阶段映射到学生 `ceil(j*S/M)` 轮，最后阶段始终监督第 S 轮。

## 4. 损失与两种动态

每个 token 对其 M 个有效阶段平均 reverse KL；每条回答再按生成长度平均，最后对回答平均：

`L = mean_responses [ mean_response_tokens [ mean_selected_stages KL(p_student_slot || stopgrad(q_teacher_depth)) ]]`。

二阶段二轮学生就是 `0.5*(KL(S1||T_d1)+KL(S2||T_nt))`；仅终点时是 `KL(S2||T_nt)`，不再乘 0.5。教师、退出和选点均不接收该损失的梯度。当前第一版不叠加隐藏态 loss、教师融合、候选门控或选轮网络。

- 冻结教师：独立的初始模型快照，对应 LoopOPD 的参数策略。
- 当前教师：每次优化步用当前共享模型作停止梯度教师，对应 D-LoopOPD。

这两种参数策略都可以搭配固定出口或原生动态出口，比较时分别报告。

## 5. 可选样本筛选与实现边界

可让冻结的初始教师按同一原生动态策略完整作答一次，只缓存样本是否正确。各组共用筛选结果；训练时仍在新学生前缀上重新选择 n_t。标签不会证明所有中间预测正确。

所用 Ouro 发布源码先完成 K 轮再选读出。代码忠实保留该执行与缓存语义，记录真实循环开销；阶段端点不会变成教师跳轮路径。Huginn 已使用完整 coda 与自身 KL evaluator，教师逐前缀重建独立 `latest-m4` 缓存并实际停止后续循环；首次比较均匀分布，之后比较 `KL(q_previous || q_current)`。代码复用退出检查时已读出的分布计算 JS；学生仍固定执行 S 轮。
