# 当前认识、假设与判定标准

更新：2026-11-13。主方案为[原生退出与 JS 阶段蒸馏](loop_distillation_research_proposal_zh.md)。本次实现核验与11月8日历史小实验都不能替代正式学习收益。

| 认识 | 已有依据 | 对当前实现的约束 |
|---|---|---|
| 终点目标不唯一决定内部路径 | 条件分布目标性质 | 可研究学习难度，不能据此断言能力必然受损 |
| 精确匹配全部可达前缀的终点分布会匹配序列分布 | 自回归分解 | 研究有限预算与优化限制 |
| 参数刷新与动态退出是两个维度 | LoopOPD Eq.9/11 与 Ouro 退出实现 | 八种配置分别记录，不混淆归因 |
| 原生退出不保证正确 | gate 的预测含义与动态退出研究 | 可选结果筛选只给样本标签 |
| JS 大只表示分布转折 | 标准 JS 的定义 | 不作为正确性或因果贡献标签 |
| 可读答案与可重用状态不同 | Compute/Retain/Reuse | 读出监督未必捕获全部关键功能 |
| 一些 query 更新有任务作用 | 文献与本地历史冻结／移植实验 | 可设计后续机制检验，不能直接认定 JS 已选对 |
| 选较早出口不一定省实际计算 | 所用 Ouro 先算 K 轮再选状态 | 成本报告实际执行量 |
| 确定性 Ouro 当前教师同深度目标可能只是自对齐 | 同权重、同前缀的相同出口分布 | 记录 T1→S1 等比例；Huginn 原生随机初态的独立抽样另行解释 |

## 待验证的主要假设

| 编号 | 假设 | 支持所需证据 |
|---|---|---|
| H1 | 原生动态监督终点更合适 | 同参数刷新策略下 B 优于 A，且不是样本／成本差异 |
| H2 | 增加阶段目标有学习价值 | C 相对 B 的无干预学生结果与成本 |
| H3 | JS 转折比均匀位置更合适 | 数量匹配的 D 优于 C，多个 seed、留出任务 |
| H4 | 阶段承接改善固定浅轮学习 | 固定 S 学生的实际训练曲线与最终能力，不能只看局部 KL |
| H5 | 关键跨轮探索解释成立 | 选中阶段的干预后果、修正／改错分解，区别于一般过程监督 |
| H6 | 结果筛选的收益值得成本 | 共用筛选池、另做无筛选对照，计入一次教师作答 |

## 结果应怎样改变主张

- B 与 A 相当：原生出口带来的收益未建立，先复核阈值和退出分布。
- C 与 D 相当：转折选点没有额外证据，采用更简单映射。
- D 大量退化为终点：报告实际覆盖，不把方法名字当作发生了阶段蒸馏。
- 原生退出多落在 n_t<=S：这些位置按计划仅终点监督，不强加中间项。
- 只看到熵或 JS 改善：尚未建立固定浅轮的任务收益。
- 更新导致正确候选下降：分解纠错／改错，而非把一切变化统称探索。
- CPU 随机模型更新正常：说明代码可运行，不说明真实 Ouro/Huginn 方法有效。

代码核验和原文参数对应见[实现文档](08_implementation_and_reproduction.md)。

Huginn 原生接口对齐、预训练权重短 CPU 前向和随机小模型训练只建立工程可行性。当前教师与学生采用独立的原生随机初态，损失对应这些抽样后的预测；尚未边缘化初态随机性，也未证明预测差异来自深度本身。固定 S 学生全轮反传与 BoD 的截断重算应分别记录。
