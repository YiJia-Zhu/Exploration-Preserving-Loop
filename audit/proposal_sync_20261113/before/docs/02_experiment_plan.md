# 当前实验方案：LoopOPD 基线与 A/B/C/D

更新：2026-11-13。方案定义来自[当前计划](loop_distillation_research_proposal_zh.md)，代码与原文参数的逐项关系见[实现文档](08_implementation_and_reproduction.md)。旧的十九组候选保留实验矩阵已归档，不作为本轮排程。

## 1. 最小对照

| 组别 | 教师监督出口 | 学生监督点 | 回答什么 |
|---|---|---|---|
| A | 固定 K=4 | 只有 S2←T4 | LoopOPD / D-LoopOPD 原目标 |
| B | 原生退出 n_t | 只有 S2←T_n_t | 动态监督终点的作用 |
| C | 与 B 同一退出策略 | 均匀分段的段末 | 中间监督本身的作用 |
| D | 与 B 同一退出策略 | JS 最大转折分段的段末 | 本次主体方案 |

每组分别提供冻结教师与当前共享教师配置，共八份。A 的当前教师版本对应 D-LoopOPD；B/C/D 是在相同参数刷新策略上的新增方法。不能把 A 的冻结教师与 D 的参数刷新混在一起，归因于 JS。

C 默认按同一前缀上 JS 规则产生的阶段数量进行匹配，但用均匀位置，而非 JS 最大位置。这样 C/D 目标数量相同；无明显转折或 n_t<=S 时两组都退回终点。不同方法训练后的学生前缀会分化，不强行复用跨组 n_t。

## 2. 尽量对应原论文

Ouro-1.4B-Thinking，K=4、S=2；DAPO-Math-17k 17,398 题；prompt 上限 1,024；32 prompts × 8 responses = 256 条回答／更新；100 次更新。AdamW，LR 1e-6，weight decay 0.01。LoopOPD 无 warmup，D-LoopOPD warmup 10 步。生成最多 31,744 token，温度 1.0，top-p 1.0。AIME 验证温度 1.0、top-p 0.7、每题 16 次，最多 31,744 token。

上述来自原文 Appendix B、Appendix C Table 4、Appendix D Tables 7–9。seed、AdamW betas/eps、精度、过长 prompt 处理及并行实现等未被原文充分指定，配置明确记录本实现选择。原始训练代码当前仍未公开，不声称已达到其表格分数。

## 3. 先完成接口与语义核验

1. 原生各轮状态已经 final norm，避免二次归一化；退出 CDF 与官方 forward 在相同输入上对齐。
2. 固定 S 的独立生成策略真正只计算 S 轮；学生和教师使用各自 KV，训练 loss 前向分别重算同一文本。
3. 生成回答的第一个 token 对应 prompt 末位置；只监督生成部分，包括实际生成的 EOS；不把 prompt 或 padding 当回答。
4. 标准 JS 的方向、单位、阈值、边界索引和回退正确；最后目标始终是 n_t。
5. 教师与分段停止梯度；当前教师在整个全局 batch 内固定，到下一次优化更新后才刷新。
6. 按 token／阶段／回答三层归一化；读出分块与不分块的损失和梯度一致；重计算与恢复不改变目标。

当前已执行的 CPU 检查及随机微型模型训练由实现文档列证据。它们检查实现语义，不验证真实模型学习收益。

## 4. 数据与阈值

正式输入使用有来源与哈希的 DAPO JSONL。尽量保留原始消息模板；输入是裸 problem 时追加原文数学指令，并明确记录适配。源数据题数不符会报错，不自动改用 17,162 题或其他项目的处理版。

训练、阈值校准、开发与测试按题目去重划分。原生退出阈值和 JS 阈值只用训练开发数据。0.9／0.01 nats 为初始候选值，尚未校准。每轮先检查退出分布，避免所有位置都最浅／最深退出或全部仅终点，使方案实际上退化。

可选正确性筛选使用冻结初始教师、相同原生动态策略，每题一次完整回答。A/B/C/D 共用被接受题目池；缓存核对模型 revision、退出／采样设置及题目内容哈希。训练只读接受标签，不读离线退出深度。另做无筛选对照，成本分别记。

## 5. 指标与成本

主指标为固定 S 轮、无外加干预学生的任务表现。AIME24/25/26 分别 30 题，报告 Avg@16 和 Pass@16；OlympiadBench 675、BeyondAIME 100，原文每题一次。内置评测器只验证 boxed 整数，符号等价及 EvalPlus 使用外部正式评测器，不能混报为完整论文协议。

同时报告：n_t 直方图、n_t<=S 比例、每个 token 阶段数、各学生轮对应的教师深度、仅终点比例、真实 teacher/student token-loops、读出、生成长度、截断、时间及显存。累计退出概率达到阈值不表示正确；选择 n_t 不代表源码真正少执行了 K−n_t 轮。

正式报告需要多个 seed，以及相同样本与总成本比较。先验证 A，随后 B/C/D；只在这些差异建立后增加 KL、段首、随机映射或 Huginn 对照。查询冻结／恢复仅作独立机制诊断，不进入主训练选点。
