# 当前认识与待验证假设

以[动态学生主方案](loop_distillation_research_proposal_zh.md)为准。

| 判断 | 依据与限制 | 实验约束 |
|---|---|---|
| JS只描述分布变化 | 高变化可来自修正，也可来自振荡或改错 | 不把边界直接当因果价值标签 |
| 所有小变化也可能累积漂移 | 相邻阈值不控制整段首尾距离 | 统计长段漂移，观察是否过度压缩 |
| S_t是监督标签 | 部署只看学生自己的停止头 | 实测S_hat_t及误差，不用S_t代替推理成本 |
| 动态上限K不等于固定运行K | 真实循环可能提前停止 | 同时报告轮数和完整执行工作量 |
| Ouro原生教师可能仍算全K | 官方发布执行与退出读出分离 | 原生A也分开记录选择深度与执行深度 |
| 前缀重算消除了缺失KV近似 | 代价是重复计算已有前缀 | 不能据轮数降低宣称延迟已改善 |
| 参数刷新与计算动态是两件事 | 原LoopOPD/D-LoopOPD定义 | 冻结／current分别对照 |
| Huginn有原生随机初态 | 同深度、同参数读出也可能不同 | 独立抽样差异不能直接归因于深度 |

## 主张需要什么证据

E需在精度—真实计算或耗时曲线上优于B，并与C/D比较，区分停止学习、阶段监督和JS位置的作用。E与F比较，判断动态阶段数是否比固定预算更合适。

如果C已达到E效果，中间阶段监督的额外价值未建立；如果D与E相当，复杂JS定位的价值未建立；如果停止过早导致性能下降，退出头就是当前瓶颈。若S_t普遍等于n_t，说明阈值没有压缩；若普遍为1，则主体实际上接近动态终点训练。

确定性Ouro当前共享教师的同深度自对齐可能没有新信息；Huginn初态随机性还会产生同深度差异，二者都需结合深度映射解释。CPU随机小模型、真实权重短前向、保存恢复通过，均只支持工程语义，不能证明必要探索或正式任务收益。
