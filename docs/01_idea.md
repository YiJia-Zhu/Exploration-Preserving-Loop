# 当前 Idea：JS阈值阶段数与动态学生退出

以[主方案](loop_distillation_research_proposal_zh.md)为准。方法直接改进LoopOPD：保留相同学生前缀和reverse KL，把固定深轮终点目标扩展为阶段目标，再联合学习停止。

## 核心逻辑

1. 学生按自己的停止头生成回答，实际深度记为 `S_hat_t`。
2. 教师读取相同学生文本前缀，以自己的原生规则选择终点 `n_t≤K`，使用独立状态与缓存。
3. 对前 `n_t` 轮计算标准相邻JS，保留**所有** `JS>τ` 的边界，取每段末轮。阶段数为 `S_t`，不排序、不截断Top-S。
4. 学生第j轮学习第j段末分布，最后一轮对应教师 `n_t`。阶段KL先按该token的阶段数平均。
5. 学生第1至 `S_t−1` 轮标记继续，第 `S_t` 轮标记停止。退出头BCE与阶段KL相加。

六轮例子：转折在3→4，则学生两轮学3、6；转折在2→3和4→5，则三轮学2、4、6；无转折则一轮学6。所有边界都超阈值时，学生目标与教师同深度，该位置不压缩。`n_t=1`自然得到一轮目标，没有旧版 `n_t≤固定S` 回退。

## 部署与默认值

部署仅用学生，本地停止概率≥0.5退出，未满足则到K。Ouro复用已有gate；Huginn增加读取归一化循环状态的线性头。教师出口仍为Ouro累计概率／Huginn原生KL，不能与学生停止概率混写。

当前默认 `configs/default.json` 指向E组冻结教师版。Ouro上限4，Huginn上限32；τ=0.05 nats、β=1尚未校准。Huginn新退出头初始化weight=0、bias=−2；Ouro保留原始gate，不重置。

旧版固定S、最多Top-(S−1)边界、有序映射保留为F。它不再是默认方法。实现、缓存和真实成本边界见[实现说明](08_implementation_and_reproduction.md)。

新增[边界信号与正确性消融](12_confidence_and_correctness_ablations.md)：以最大概率、归一化熵或prompt探针信心的变化替代JS；比较教师正确题目池、同数量随机题目和不筛选版本。默认仍是JS且不筛选，所有新信号组保留动态学生，不固定实际循环数。
