A BSTRACT
Looped Language Models (LoopLMs) offer a parameter efficient approach to scaling reasoning by reusing shared parameters across recurrent computation steps.
Despite their promise, effective post-training of LoopLMs remains challenging.
Existing approaches either provide reward based supervision that is sparse or
costly to extend across loops, or rely on external teachers or privileged information, leading to limited teacher availability or teacher-student context mismatch.
To address these limitations, we introduce LoopOPD, a cross-loop on-policy distillation framework that uses additional recurrent computation within a LoopLM
as its own source of supervision. LoopOPD uses a frozen terminal loop policy
as a compute privileged teacher for an intermediate loop student on student generated rollouts, providing dense supervision without an external teacher or privileged information. We further propose Dynamic LoopOPD (D-LoopOPD), which
continually refreshes the terminal loop teacher as the shared model parameters
are updated, enabling recurrent self-improvement. We characterize how distillation updates propagate across loop depths and derive sufficient conditions under
which a single update yields simultaneous local improvement at both loop depths.
Experiments on Ouro-Thinking models show that LoopOPD improves mathematical reasoning, while D-LoopOPD yields further gains through dynamic teacher
updates. Despite being trained only on mathematical data, the resulting models
also improve on general reasoning and code generation benchmarks, demonstrating that recurrent computation can serve as an effective source of supervision for
LoopLMs. Our code and model checkpoints will be released upon acceptance.

I NTRODUCTION

Looped Language Models (LoopLMs) have recently received growing attention as a promising approach to scaling reasoning through recurrent depth (Geiping et al., 2025). They reuse shared Transformer blocks across multiple latent computation steps before emitting each token (Zhu et al., 2025).
This design increases computational depth without increasing parameter count, leading to stronger
reasoning performance (Saunshi et al., 2025). However, effective post-training of LoopLMs remains
challenging. Existing work applies or extends conventional post-training methods to LoopLMs, including reward based optimization and distillation, but faces limitations (Williams et al., 2026).
Specifically, prior work on Ouro, a family of pretrained LoopLMs (Zhu et al., 2025), reports limited gains from reinforcement learning with verifiable rewards (RLVR) (Guo et al., 2025) over
the supervised fine-tuning (SFT) checkpoint. Group Relative Policy Optimization (GRPO) (Shao
et al., 2024) assigns reward credit only to the terminal loop, leaving intermediate latent computation
without direct reward supervision. Reward Latent Thought Trajectories (RLTT) (Williams et al.,
2026) alleviates this limitation by extending reward credit across all loops, but requires retaining
per loop log-probabilities, causing memory usage to scale linearly with the number of loops and
thereby limiting long rollout training. On-Policy Distillation (OPD) (Agarwal et al., 2024) provides
dense distributional supervision but relies on an external, stronger teacher. For Ouro-2.6B-Thinking,
no stronger same family LoopLM teacher is available, limiting OPD. On-Policy Self-Distillation
